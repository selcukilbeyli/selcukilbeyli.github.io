# Selçuk İlbeyli — Independent Researcher

Modern, responsive, animated academic homepage.

## Publish with GitHub Pages
1. Create a public repository named `selcukilbeyli.github.io`.
2. Upload `index.html` to the repository root and commit.
3. Under Settings → Pages, select Deploy from a branch → main → /(root).
4. Open https://selcukilbeyli.github.io once deployment completes.

## Customization
- Edit research and publication sections directly in `index.html`.
- Edit the `entries` JavaScript array for journal cards.
- Edit CSS variables in `:root` for colors.

## Note
This is a static prototype. The journal entries are illustrative placeholders.
A CMS and authentication setup is required for direct editing at `/admin`.
